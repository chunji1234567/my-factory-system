## 一、排产（生产之前必做）

**触发时机**：决定要做哪张单、多少个。

### 步骤

1. 侧栏点 **排产中心**
2. 从"待排"列表里找到那张销售订单明细
3. 输入**本次排产数量** + **排产日期** 
4. 点 **一键排产**
5. 确认 → 系统**自动扣料**（外壳 + PCB 板 + 线材 + 原材料）

> [截图：排产中心列表]
> [截图：一键排产弹窗]

### 备货模式（没有客户订单也要先生产）

有时候产线要**先做一批放着**，之后哪个客户要就发给谁。这种情况：

1. 找老板 / 管理员创建一张"**内部备货订单**"——合作方选**自己公司**、随便填个价格
2. 你按上面的正常流程给这张备货单**排产 + 扣料**
3. 等真的有客户下单要提货时，让老板把这张单的**合作方改成实际客户**，然后正常发货

这样备货的用料 / 成本 / 库存都在系统里有记录，不会变成"黑产"。

### 注意

- ✅ **扣料成功 = 材料齐**，可以放心开工
- ⚠️ **系统允许库存扣成负数**——就算某个料没了也能排产，系统不拦你。
  但如果排完看到**某个物料变红**（低于安全库存），**告诉老板补货**，别当没看见。
- ❌ 别一次把整张单的量全排——按今天实际能做多少排

## 二、发货（每天最主要的事）

**触发时机**：货打包好、准备贴快递单/交给司机，**贴单前录系统**。

### 步骤

1. 侧栏点 **发货控制**
2. 找到今天要发的销售订单
3. 每一行看**可发数量**（= 已生产 - 已发货）
4. 点 **新增发货**
5. 填：
   - **本次实发数量**（不能超过可发数量）
   - **快递单号 / 物流单号**
   - 备注（可选，比如"寄了 2 箱"）
6. 确认

> [截图：发货控制列表]
> [截图：新增发货弹窗]

### 打印发货单

发货后，可以点这张单的 **导出 PDF** → 打印 → 随货交给司机 / 客户。

> [截图：导出 PDF 按钮 + 打印出来的样子]

### 注意

- ✅ 实发数量 = 真的贴单上的数量
- ✅ 快递单号必须填对，客户可能问
- ❌ 别先发货后录——**先录后发**，防止漏录

## 常见问题

**Q：可发数量是 0，客户催货怎么办？**
A：说明还没排产 / 排完还没入库。**先排产**（见上面第一部分），有货才能发。

**Q：客户要发货单 PDF？**
A：发货控制里找到那张单 → **导出 PDF** → 微信发给客户。

---

## 铁律

1. **先录后发**——单没录进系统的，不允许出厂
2. 快递单号**当场填**，别攒到晚上
3. 从 [切换日期] 起，**没进系统的发货，财务不认**
