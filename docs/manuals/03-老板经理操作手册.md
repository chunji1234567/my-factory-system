## 一、录销售订单（客户下单来了）

### 步骤

1. 侧栏 **销售管理** → 右上 **新增销售订单**
2. 填：
   - **客户**：从下拉里选（没有的先去"合作方与结算"加）
   - **客户订单号**：客户自家系统的单号，有就填，没有留空
   - **预计交付日期**：答应客户的交期
3. 加**订单明细**（客户买的每种产品一行）：
   - 客户侧产品名（写客户能看懂的）
   - **外壳**（下拉选）
   - **PCB 方案**（下拉选，事先在"PCB 方案"里维护好配方）
   - **线材**（下拉选）
   - 数量、单价
4. 保存 → 系统自动算总金额

> [截图：新增销售订单表单]
> [截图：明细行 三件槽位]

### 导出订单确认书（给客户签字）

订单列表 → 找到这张单 → **导出 PDF** → 微信发给客户签字回来。

> [截图：导出 PDF 按钮 + 生成的 PDF 样子]

### 归档 / 修改 / 删除

- **归档**：完成的订单点归档，从日常列表隐藏（财务台账还会显示）
- **改价改数量**：**不要直接改老订单**，走"合作方与结算 → 新增流水"做**调账**——保留审计痕迹
- **删除**：极少用，一般归档就够

## 二、录采购订单（要买料了）

流程和销售订单一样：

1. **采购管理** → **新增采购订单**
2. 选供应商、供应商单号、预计到货日期
3. 加明细：物料 / 数量 / 单价
4. 保存 → 导出 PDF 发给供应商确认

> [截图：新增采购订单]

**收货由仓库做**，你不用管，收完后订单状态自动变。

## 三、维护主数据（每个新东西第一次出现时）

### 加新客户 / 供应商
**合作方与结算** → **新增合作方** → 选客户/供应商/两者兼有

### 加新物料
**库存中心** → **新增产品** → 选分类（原材料/自产件/线材/成品）+ 编号 + 型号

### 加新 PCB 方案（重要！）
**PCB 方案** → **新增方案** → 加明细（用到的每种**原材料** + 每块板的用量）
排产时会按这个配方**自动扣料**，配方错了扣料就错。

## 四、财务 / 对账

### 看每个客户/供应商欠多少

**合作方与结算** → 顶部两个 tab：**应收** / **应付** → 每行显示当前余额

> [截图：合作方余额列表]

### 录一笔往来（客户付款 / 你付供应商）

进合作方详情 → **流水** tab → **新增流水** → 选类型 + 金额 + 备注

### 导出年度对账台账

合作方详情 → **导出台账** → 选月份区间 → 下载 xlsx（顶部会显示当前余额）

> [截图：导出台账按钮 + 生成的 xlsx 样子]

## 五、经营分析（每周或月底看）

**经营分析** 面板（**只有你能看**）：

| 模块 | 用来看什么 |
|---|---|
| 销售/采购趋势 | 本月赚了多少、买了多少料 |
| 排产吞吐量 | 车间产能有没有跟上 |
| 物料消耗（实际） | 车间真实用了多少料 |
| 方案销售 | 哪个 PCB 方案卖得好 |
| 物料需求（订单展开）| 未生产的订单要多少料 → 提前采购 |
后续会根据需求增加新的功能 

**关键对比**：物料需求 − 物料消耗 ≈ **待生产的缺口**，能看出排产跟不跟得上。

## 六、每天巡查（5 分钟）

早上或下班前扫一眼：

1. **销售管理** → 有没有新订单没跟进
2. **采购管理** → 供应商到货了没
3. **排产中心** → 待排的单排完了吗
4. **合作方与结算** → 谁欠款超期了
